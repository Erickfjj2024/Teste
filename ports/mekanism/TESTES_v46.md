# Teste de diagnóstico: APK v46 (barra de energia)

Instale o APK `horizon-android-v46.apk`. Olhe o item do Energy Cube (dropado, com energia) na hotbar e no inventário e me diga a cor da barra:

| Cor | Significa |
|---|---|
| Verde-água proporcional | Funcionou |
| Azul cheia | O desenho do item chega, mas o item não tem dados do bloco (nem nenhum outro dado) |
| Branca cheia | O item tem outros dados mas não os do bloco |
| Vermelha / amarela cheia | O item tem dados do bloco (sem energia / energia sem conta) |
| Nenhuma | O desenho do item não passa pelo meu código |

Olhe também um cubo pego do criativo (sem energia): deve aparecer azul.
