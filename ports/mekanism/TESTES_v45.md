# Teste de diagnóstico: APK v45 (barra de energia)

Instale o APK `horizon-android-v45.apk`. Este APK mostra uma barra de **cor de diagnóstico** quando o item do cubo tem dados do bloco mas a barra normal não saiu. Me diga qual cor vê no item do cubo (dropado, com energia) na hotbar/inventário:

| Cor da barra | Significa |
|---|---|
| Verde-água proporcional à energia | Funcionou |
| Vermelha (cheia) | O item tem dados do bloco, mas sem a energia dentro |
| Amarela (cheia) | O item tem a energia, mas a conta da barra não deu resultado |
| Nenhuma barra | O item nem chega com dados do bloco ao desenho |

Teste também com um cubo vazio (sem energia): quebrar e olhar o item.
