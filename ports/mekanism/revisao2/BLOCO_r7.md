### 21.7 Transmissores e Armazenamento (mod 0.1.86, revisão cruzada contra Mekanism 1.21.1-10.7.19.85)

| # | Diferença / Difference | Estado / State |
|---|---|---|
| 21.7.1 | Capacidade interna de Tubos e Canos: a API do Horizon no WASM define apenas `throughput` no `TransmitterSpec` (o port utiliza as taxas de extração/pull do Java: 750/2.000/64.000/256.000 mB/t para tubos e 250/1.000/8.000/32.000 mB/t para canos). A capacidade individual por bloco de rede (4.000–1.024.000 mB em tubos; 2.000–128.000 mB em canos) não é exposta na API do Horizon | FORK (FORK-1) |
| 21.7.2 | Logistical Transporter (velocidade e variantes): a velocidade de trânsito dos itens nos dutos (5, 10, 20, 50 ticks) não é configurável no Horizon (apenas taxa de pull 1, 16, 32, 64 itens). Variantes Restrictive Transporter (custo 1.000) e Diversion Transporter (modos de sinal redstone por face) não existem no port | FORK (FORK-2, FORK-3) |
| 21.7.3 | Thermodynamic Conductor (Calor): condutores térmicos e meio de calor não implementados no port (o Horizon não possui sistema genérico de transferência de calor nem API de condutores térmicos) | FORK (FORK-4) |
| 21.7.4 | Creative Bin e Creative Energy Cube: no Java as capacidades nominais são infinitas (`Integer.MAX_VALUE` no bin com supressão de decréscimo; `Long.MAX_VALUE` no cube para capacidade e saída). No port são representados como `u64::MAX / 2` no bin e 1 trilhão de FE (saída 1 bilhão de FE/t) no cube para prevenir overflow aritmético e suportar sincronização de tela em 32 bits | FORK (FORK-5) |
| 21.7.5 | Reatividade a Redstone em Transmissores: no Java (`Transmitter.java:421`), cabos, tubos e canos energizados com redstone desconectam a rede (`canConnect = false`). No port, o estado redstone é alternado pelo configurador e salvo em bytes, mas não interfere nas conexões da rede do jogo por falta de hook na API | FORK |
| 21.7.6 | Moldura/Arestas da Induction Matrix: no Java (`CuboidStructureValidator.java:115, 149`), os 12 blocos de aresta da casca exigem `Induction Casing` (vidro estrutural é aceito unicamente nas faces/paredes planas). No port, `Part::Casing` engloba tanto `Induction Casing` quanto `Structural Glass` sem distinguir faces de arestas | FORK / SUPOSIÇÃO |
| 21.7.7 | Bins (Ataque e Lock): no Java (`BlockBin.java:38-71, 88`), bater com soco no bin retira 1 item (ou 1 stack com sneak) e shift-clique com a mão vazia na frente bloqueia/desbloqueia o item. No port, o Horizon não possui evento de ataque a blocos na API (extração apenas por GUI/automação), e o bloqueio é controlado via botão na interface gráfica | FORK API |
| 21.7.8 | Bounding Blocks (Interação e Redirecionamento): no Java (`BlockBounding.java`), cliques em blocos subordinados são encaminhados para a máquina principal (abrindo sua GUI ou interagindo com ferramentas). No port, blocos subordinados apenas ocupam espaço físico e não redirecionam eventos | FORK API |
